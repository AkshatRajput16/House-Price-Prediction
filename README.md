# House-Price-Prediction
House Price Prediction using Linear Regression
Objective of this project is to develop a regression model that can accurately predict house prices based on different house features.

Dataset:House Price Dataset

Technologies Used :
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

Project Workflow
- Import dataset
- Explore the dataset
- Handle missing values
- Encode categorical variables
- Make predictions
- Evaluate model performance

 Model Used -Linear Regression
